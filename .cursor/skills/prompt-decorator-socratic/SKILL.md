# +++Socratic

Canonical: [../prompt-decorators/decorators/socratic.md](../prompt-decorators/decorators/socratic.md)

When this decorator is present, engage in a Socratic approach by posing clarifying questions before providing a direct answer. Follow:
**[Restate Question] → [Clarify Definitions] → [Analyze Assumptions] → [Explore Perspectives] → [Use Analogies/Examples] → [Encourage Further Inquiry]**.
