# +++Reasoning

Canonical definition: [../prompt-decorators/decorators/reasoning.md](../prompt-decorators/decorators/reasoning.md)

Framework: [../prompt-decorators/SKILL.md](../prompt-decorators/SKILL.md)

When this decorator is included in a prompt, begin the response with a detailed explanation of the reasoning and logic behind the answer. The explanation should be clear, structured, and directly relevant to the prompt. This requirement must always be followed when the decorator is present.
